## Вывод по расхождению

- **Пропущенный блок:** существенных пропусков не было; при вёрстке уточнён модификатор `button--ghost-dark` для карточек destinations.
- **Самая недооценённая задача:** адаптив 360px + мобильная навигация — план 2.2 ч, факт 3.5 ч.
- **Затруднение:** написание `css/style.css` заняло больше времени, чем ожидалось — файл большой, много секций.
- **Пункт в чек-лист:** проверять DevTools на 360 / 768 / 1280 после каждой новой секции до коммита.

## Принятые решения

- `blog.html` — статья, а не список.
- Форма `join-form` переиспользуется на обеих страницах.
- Мобильная навигация: вертикальный список до 768px, иконки поиска/профиля остаются.
- Логотип двумя строками: «Talking» рукописным шрифтом, «Travel» жирным гротеском.
- Hero-фон: CSS background-image + overlay для контраста.
- Кнопки «Watch highlights» и «Watch Now» — ссылки с иконкой play.
- Кнопки Discover ведут на якоря в blog.html.
- Промежуточные ширины: одноколоночная база, расширение с 768px.

## Проверка

- Валидатор W3C — без ошибок.
- Tab-навигация: все ссылки и кнопки достижимы, фокус виден.
- Контрольные ширины: 360 / 768 / 1280 px.
- Нет горизонтальной прокрутки на 360px.
- Lighthouse Accessibility ≥ 90.
