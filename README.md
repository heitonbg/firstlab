## Принятые решения

- `blog.html` — статья, а не список.
- Форма `join-form` переиспользуется на обеих страницах.
- Мобильная навигация: вертикальный список до 768px.
- Логотип двумя строками.
- Hero-фон: CSS background-image + overlay.
- Кнопки Watch highlights / Watch Now — ссылки с play.
- Промежуточные ширины: одноколоночная база.
