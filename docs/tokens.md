# Словарь токенов проекта — Talking Travel

## Ширины
- Контейнер: 1200px
- Внешние поля: 24px (360), 40px (768), авто (1280)
- Контрольные ширины: 360 / 768 / 1280

## Типографика
- Основной шрифт: "Inter", system-ui, sans-serif
- Логотип "Talking": рукописный шрифт (заменим на cursive / Sacramento), 20px
- Логотип "Travel": гротеск, 24px, 800
- H1 (hero): clamp(2rem, 1.2rem + 3vw, 3.5rem), 700, две строки
- H2 (секции): clamp(1.5rem, 1rem + 2vw, 2.25rem), 700
- H3 (карточки): 1.25rem, 600
- Body: 1rem / 1.5
- Надзаголовок (eyebrow): 0.75rem, uppercase, letter-spacing 0.08em, акцентный цвет
- Muted-текст: 0.875rem

## Палитра
- Текст: #1b1b1f
- Muted: #5b5b66
- Акцент: #7B5BF5  (фиолетовый из макета)
- Акцент hover: #6344E0
- Фон страницы: #ffffff
- Фон hero-подложки: фотография
- Поверхность карточек: #f6f7f9
- Границы: #e5e7eb

## Шаг отступов
0.5rem / 1rem / 2rem / 4rem (space-2, space-4, space-8, space-16)

## Радиусы и тени
- Радиус: 12px (карточки, кнопки), 999px (пилюли)
- Тень: 0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)

## Повторяемые компоненты
- Кнопка (primary — фиолетовая, ghost — с иконкой play)
- Иконка play (кружок + треугольник)
- Карточка направления (Iceland, Italy, Dubai, Patagonia)
- Featured-блок (текст + фото)
- Пункт навигации
- Логотип двумя строками

## Состояния
- hover, focus-visible, active, disabled
- фокус: outline 2px акцентного цвета, offset 2px

## Принятые решения (чего нет в макете)
- Мобильная навигация: вертикальный список до 768px, иконки поиска/профиля остаются.
- Промежуточные ширины: одноколоночная база, двухколоночная с 768px.
- Логотип "Talking" рукописным шрифтом — подключаем Google Font "Sacramento" или используем cursive fallback.
- Длинные заголовки: text-wrap: balance.
- Hero-фон: изображение через CSS background с overlay для контраста текста.
